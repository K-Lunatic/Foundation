**게임 · 임베디드 · 인공지능**을 중심으로, 입력과 데이터를 사용자 경험으로 연결하는 도구를 만듭니다.

AI 분야의 현재 강점은 기존 모델을 활용하는 도구와 데이터 처리 흐름입니다. 모델 학습·성능 개선을 완료한 연구 성과와는 구분합니다. Catpera와 Void도 완성된 메타버스 플랫폼이나 상용 게임으로 소개하지 않습니다.

## 세 분야의 위치

- **게임:** 3D·오디오·상태 변화·사용자 입력 경험을 바탕으로, 플레이 가능한 게임과 게임 시스템 구현을 심화합니다.
- **임베디드:** C·통신·기기 제어 경험을 정리하고 MCU·RTOS·디버깅으로 확장합니다. 여기서는 실제 장비 검증이 끝난 대표작을 제시하지 않습니다.
- **인공지능:** 학습 자료의 구조화, 원문 근거 추적, AI 활용 워크플로를 다룹니다. 검색·매칭 정확도 평가를 다음 과제로 둡니다.
