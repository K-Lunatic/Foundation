| 프로젝트 | 해결하는 문제·경험 | 구현 |

| [Our-Frequency · 과제 제출판](https://github.com/K-Lunatic/Our-Frequency) | 질문·사주 입력과 결과·궁합 시각화 | React · TypeScript · Vite · Three.js |
